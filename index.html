Welcome to Resource Alchemy Hacker

Resource Alchemy Hacker is a comprehensive 32-bit and 64-bit resource compiler and decompiler for Windows executable files. Developed by EliteSoftwareTech Co., it allows you to deeply inspect, modify, add, extract, and delete resources in Win32/Win64 PE (Portable Executable) files.

With its robust command-line CLI tool for automated build pipelines and an intuitive graphical user interface (GUI) designed strictly with legacy Windows aesthetic principles, you have complete control over your application's compiled resources.

Key Features

Comprehensive Extraction

Extract strings, dialogs, menus, icons, bitmaps, cursors, and raw binary data from any compiled Windows application.

Seamless Resource Modification

Dynamically swap out application icons or modify internal manifests without recompiling the original source code. Perfect for localization or theming.

CLI & GUI Dual Operation

Designed to be utilized by automated scripts via its powerful CLI module, or explored interactively using the legacy-styled GUI.

Integrated Authenticode Signing

Automatically re-sign modified PE files using native Microsoft Crypt32 API integrations, ensuring your tailored executables remain compliant.
